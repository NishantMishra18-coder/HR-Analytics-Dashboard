# HR Analytics Dashboard 📊

## Project Overview

The HR Analytics Dashboard is an interactive Power BI project designed to analyze workforce data and provide insights into employee demographics, salary distribution, work experience, job roles, and job satisfaction.

The dashboard helps HR professionals understand workforce patterns and make data-driven decisions.

## 🎯 Project Objectives

* Analyze employee demographics and workforce distribution.
* Understand department-wise employee distribution.
* Explore salary distribution and employee experience.
* Analyze job satisfaction and employee-related trends.
* Present HR data through interactive visualizations and filters.

## 🛠️ Tools & Technologies

* **Microsoft Power BI** – Dashboard development and data visualization
* **CSV / Excel** – Dataset storage and data preparation
* **Power Query** – Data cleaning and transformation

## 📈 Dashboard Features

* **KPI Cards:** Total Employees, Average Age, Average Years of Experience, and Annual Salary.
* **Department Analysis:** Employee distribution across departments.
* **Salary Analysis:** Employee distribution across salary ranges.
* **Age Analysis:** Age-group distribution.
* **Gender Analysis:** Workforce distribution by gender.
* **Experience Analysis:** Employee experience insights.
* **Job Role Analysis:** Job roles and job satisfaction.
* **Interactive Filters:** Age Group and Department.

## 📂 Project Files

* `HR_Analytics_Dashboard.pbix` – Power BI dashboard file.
* `HR_Analytics_Dashboard_Dataset.csv` – Dataset used for analysis.
* `dashboard_screenshot.png` – Dashboard preview.

## 💡 Key Insights

The dashboard can help users explore:

* Workforce distribution across departments and job roles.
* Employee demographics, including age and gender.

## 🚀 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. If prompted, update the dataset path to the downloaded CSV file.
4. Refresh the data if required.
5. Explore the dashboard using the interactive filters.
